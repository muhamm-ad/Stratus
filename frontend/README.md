# Stratus Frontend

React + TypeScript UI for [Stratus](https://github.com/muhamm-ad/stratus) — a multi-cloud VM gateway desktop app built with [Wails](https://wails.io/).

This repository holds the web frontend only. It can be developed in a browser with mock data, or embedded into the Stratus Go desktop shell via a Git submodule.

## Tech stack

| Layer | Choice |
|---|---|
| Framework | React 18 |
| Language | TypeScript |
| Bundler | Vite 8 |
| Styling | Tailwind CSS v4 |
| State | Zustand |
| Icons | Lucide React |
| Desktop bridge | Wails generated bindings (`wailsjs/`) |

## Prerequisites

- **Node.js 20+** (see `.nvmrc`)
- **npm** 10+

For full desktop integration you also need the [Stratus](https://github.com/muhamm-ad/stratus) backend repo with Go 1.25+ and the Wails CLI.

## Quick start (standalone browser)

Develop the UI without the Go backend. `src/lib/bridge.ts` serves mock VM, audit, and CLI data when Wails is not present.

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

### Other scripts

```bash
npm run build    # typecheck + production bundle → dist/
npm run preview  # serve the production build locally
```

## Project structure

```
frontend/
├── src/
│   ├── features/     # screens (auth, inventory, sessions, audit, settings)
│   ├── shell/        # layout chrome (sidebar, status bar)
│   ├── store/        # Zustand app state
│   ├── lib/          # bridge facade, formatters (call bridge, not wailsjs)
│   ├── ui/           # shared UI primitives
│   ├── types/        # TypeScript domain types
│   └── styles/       # theme tokens
├── wailsjs/          # Go ↔ JS bindings (see below)
├── dist/             # production build output (gitignored)
├── index.html
├── vite.config.ts
└── package.json
```

**Important:** application code should import from `@/lib/bridge`, not from `wailsjs/` directly. The bridge provides mock fallbacks for browser-only development.

## Wails bindings (`wailsjs/`)

The `wailsjs/` directory contains JavaScript/TypeScript bindings for the Go `internal/app.App` struct. They are **generated by Wails** from the parent Stratus repository:

```bash
# From the Stratus repo root (with this repo checked out as frontend/)
wails dev              # regenerates bindings during development
wails generate module  # regenerate bindings only
```

Committed bindings let `npm run build` and `tsc` succeed in this repo without a local Go toolchain. When the Go API changes in Stratus, regenerate bindings from the parent repo and commit the updated `wailsjs/` files here.

### Desktop build flow

From the **Stratus** repo root:

```bash
cd frontend && npm install && npm run build && cd ..
wails build
```

The parent `main.go` embeds `frontend/dist` into the desktop binary:

```go
//go:embed all:frontend/dist
var assets embed.FS
```

`dist/` must exist before `wails build` / `go build`. It is not committed in this repo.

### Desktop development

```bash
# From the Stratus repo root — hot reload + live bindings
wails dev
```

Wails runs the frontend dev server and proxies it into the native webview.

## Environment variables

Copy `.env.example` to `.env.local` if you need local overrides. Standalone development does not require backend configuration.
